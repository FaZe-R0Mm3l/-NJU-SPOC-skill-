# 安装说明 · SPOC 课程任务自动化技能

这是一份 Agent Skill（智能体技能），用于在 SPOC 平台（study.nju.edu.cn）上自动完成课程任务点：逐个翻完文档、发布讨论帖、提交作业答案。

## 一、安装前需要什么

两样东西，缺一不可：

**1. 一个支持 Skill 的 Agent 客户端**

本技能遵循通用的 `SKILL.md` 规范（YAML frontmatter + Markdown 正文 + 可选的 scripts/references/assets 目录），WorkBuddy / CodeBuddy 等支持该规范的客户端可直接识别。如果对方用的是 Claude Code，同一套结构也能用。

**2. browser-skill（bsk）浏览器自动化工具**

本技能的所有脚本都依赖 `bsk` 这条命令来驱动浏览器。没有它，脚本跑不起来。

**好消息：这个包的 `bsk-tool\` 文件夹里已经带了 bsk 工具本体，不用联网也能装。**

安装有两条路径，任选一条：

**路径一：本地安装（离线，推荐）**

进入 `bsk-tool\` 文件夹，双击：

```
双击安装.bat
```

脚本会自动把 `bsk.exe` 装好、配好 PATH、验证一遍。不用联网，不用打开 GitHub。

**路径二：GitHub 在线安装**

如果想装最新版，官方仓库在 `https://github.com/Tencent/BrowserSkill`，一条命令：

```powershell
irm https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.ps1 | iex
```

（需要能访问 GitHub，国内网络可能连不上。）

**两条路都躲不开的最后一步：装浏览器扩展**

浏览器出于安全，不允许脚本自动装扩展，这一步必须手动：

1. 打开 Chrome / Edge
2. 地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」
5. 选中 `bsk-tool\browser-extension` 文件夹

装完后确认连接：

```bash
bsk doctor
```

看到 `ok extension connected` 就说明通了。

> 详细图文步骤见 `bsk-tool\安装说明-工具.md`。

## 二、安装步骤

### 第 1 步：解压到技能目录

把压缩包里的 `spoc-course-task-automation` 整个文件夹，放到目标机器的技能目录下。

用户级（推荐，所有项目都能用）：

| 平台 | 路径 |
|------|------|
| Windows | `C:\Users\<用户名>\.workbuddy\skills\` |
| macOS / Linux | `~/.workbuddy/skills/` |

如果对方用的是 Claude Code 等其它客户端，对应目录通常是 `~/.claude/skills/`，把文件夹放进去同理。

解压后的结构应该是这样：

```
<skills 目录>/
└── spoc-course-task-automation/
    ├── SKILL.md
    ├── references/
    │   └── platform-mechanics.md
    ├── scripts/
    │   ├── run_doc.sh
    │   ├── post_reply.sh
    │   └── submit_homework.sh
    ├── deps/
    │   └── browser-skill/          ← browser-skill 技能的说明文件（Agent 用）
    ├── bsk-tool/                   ← bsk 工具本体 + 安装脚本（离线安装用）
    │   ├── windows-x64/bsk.exe
    │   ├── browser-extension/
    │   ├── 双击安装.bat
    │   ├── 本地安装.ps1
    │   ├── official-installer/install.ps1
    │   └── 安装说明-工具.md
    ├── 一键启动/环境自检.bat
    ├── 从零开始配置教程.txt
    └── 安装说明.md（本文件）
```

**注意**：必须是 `spoc-course-task-automation/SKILL.md` 这一层，不要多套一层文件夹，否则客户端扫不到。

### 第 2 步：给脚本加执行权限（macOS / Linux 需要）

Windows 可以跳过这步。

```bash
chmod +x ~/.workbuddy/skills/spoc-course-task-automation/scripts/*.sh
```

### 第 3 步：确认 bsk 在 PATH 里

在终端执行：

```bash
bsk --version
```

如果提示 `command not found`，说明没加到 PATH。Windows 下 bsk 通常装在 `~/.local/bin/`，脚本里已经写了 `export PATH="$HOME/.local/bin:$PATH"` 兜底，一般不用手动处理。

### 第 4 步：验证技能被识别

**Windows 用户**：可以直接双击 `一键启动\环境自检.bat`，它会自动检查 bsk、后台服务、技能文件三项是否就绪。

**其他方式**：重启 Agent 客户端，然后在新会话里说一句：

> 帮我在 SPOC 上完成课程任务

如果客户端正确加载了技能，它会知道自己该用什么流程、该翻哪些页面。

> 想要更详细的图文步骤（面向完全不懂技术的用户），请阅读 `从零开始配置教程.txt`。

## 三、使用方式

技能触发后，Agent 会自己按流程走。用户通常需要提供：

- **课程地址**：例如 `https://study.nju.edu.cn/portal/session/unitNavigation/<课程编号>.mooc`（把尖括号那串换成自己课程的编号）
- **任务要求**：比如"每个讨论区发 800 字以上""作业要认真答"
- **浏览器已登录**：技能复用浏览器里的登录态，所以对方需要先在浏览器里登好自己的 SPOC 账号

三个脚本也可以单独调用：

```bash
# 逐页翻完一个文档（itemid 从课程目录页里取，示例中的 1234567 请替换为实际值）
./scripts/run_doc.sh 1234567

# 在某个讨论题下发布回复（内容文件为纯文本，空行分段）
./scripts/post_reply.sh 1234567 我的回答.txt

# 提交作业答案（答案目录内按 q1.txt / q2.txt 命名）
./scripts/submit_homework.sh 1234567 ./answers
```

## 四、工作原理简述

平台判定"完成"的依据是真实的前端交互触发的上报请求，直连后端接口无效。三类任务各自的机制：

| 任务类型 | 触发动作 | 上报接口 |
|----------|----------|----------|
| 文档 / PDF | 逐页翻到最后一页 | `/study/updateDurationDoc.mooc`（末页带 `over=2`） |
| 讨论题 | 发布一条回复 | `/thread/{id}/replyThread-10.mooc` |
| 作业 | 提交答卷 | `/examSubmit/.../saveExam/...mooc` |

细节（选择器、页数读取、富文本写入方式等）都写在 `references/platform-mechanics.md` 里，Agent 需要时会自己去读。

## 五、注意事项

- **仅限本人账号使用**。技能复用浏览器登录态，请勿用于他人账号或代替他人完成任务。
- **遵守课程规定**。自动完成任务点是否符合所在课程的学术要求，由使用者自行判断并承担相应责任。部分课程明确禁止此类操作，请先确认。
- 讨论帖和作业会由同学互评或教师批阅，内容质量直接影响得分，**建议认真作答而非套用模板**。
- 平台页面结构若改版，选择器和接口可能失效，届时需要参照 `references/platform-mechanics.md` 重新核对。

## 六、出问题怎么办

先看 `references/platform-mechanics.md` 末尾的"常见故障"表，覆盖了最典型的情况：

- 调接口后刷新仍为灰 → 必须真实翻页
- 点"发布"没反应 → 按钮认错了，要用 `#btn_submit_post`
- 作业页看不到题目 → 先关"考核说明"弹窗
- 截图超时 → 改用视口截图

如果还是不行，把出错时的页面 URL 和现象告诉 Agent，让它重新观察页面结构即可。
