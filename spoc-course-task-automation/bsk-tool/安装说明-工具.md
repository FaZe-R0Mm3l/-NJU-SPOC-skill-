# bsk 工具 · 安装说明

> 整理：婉清

这个文件夹里装的是 **bsk（browser-skill）** 工具本体，用来让 AI 助手能操作你的浏览器。
有两条安装路径，任选一条。

---

## 路径一：本地安装（离线，推荐）

**适合**：不想联网、不想打开 GitHub、想一次装好。

包里已经带了完整的 `bsk.exe`，不依赖网络。

**双击运行**：

```
双击安装.bat
```

如果 Windows 弹窗提示"已保护你的电脑"，点「更多信息」→「仍要运行」。
如果提示权限，点「是」。

脚本会自动完成：复制 bsk.exe、配置 PATH、验证安装。

**或者**手动在 PowerShell 里跑：

```powershell
powershell -ExecutionPolicy Bypass -File "本地安装.ps1"
```

---

## 路径二：GitHub 在线安装

**适合**：想装最新版、习惯命令行。

官方仓库：`https://github.com/Tencent/BrowserSkill`

一条命令搞定（PowerShell）：

```powershell
irm https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.ps1 | iex
```

包里也附了一份官方脚本备份：`official-installer\install.ps1`，
万一官网地址变了，可以对照着看。

**注意**：这条路需要能访问 GitHub。国内网络可能连不上，连不上就走路径一。

---

## 两条路都躲不开的一步：装浏览器扩展

> 这一步**必须手动**。浏览器出于安全，不允许脚本自动装扩展，Chrome 和 Edge 都一样。

1. 打开 Chrome 或 Edge
2. 地址栏输入 `chrome://extensions`（Edge 输入 `edge://extensions`）
3. 打开右上角的「**开发者模式**」开关
4. 点「**加载已解压的扩展程序**」
5. 选中本文件夹下的 `browser-extension` 文件夹

装好之后，扩展列表里会出现一个叫 **BrowserSkill** 的图标。

---

## 验证装好了没

在 PowerShell 或 Git Bash 里运行：

```bash
bsk doctor
```

看到这几行就说明成功了：

```
ok    daemon running
ok    extension connected        1 browser(s) connected
```

如果 `extension connected` 那行是红色的，说明扩展没装上，回到上一步重做。

---

## 装完之后

回到上一层目录，看 `从零开始配置教程.txt`，那里讲了怎么让 AI 助手自动完成 SPOC 课程任务。

## 说明

- `windows-x64\bsk.exe`：bsk 本体（v0.3.1），约 16MB
- `browser-extension\`：浏览器扩展，约 2.7MB
- `本地安装.ps1` / `双击安装.bat`：本地安装脚本
- `official-installer\install.ps1`：官方在线安装脚本备份
